## Runtime Contract

Append `blackbody_palette_v1 = 9`. Runtime row authority stores:

- `temperature_0_k`: finite float, hard `800..40000`, default `1600`, step `50`;
- `temperature_1_k`: finite float, hard `800..40000`, default `12000`, step `50`;
- `temperature_mapping`: `reciprocal_temperature | linear_kelvin`, default reciprocal;
- derived `lut_x0`, `lut_x1`, and `lut_dx`, rebuilt from authoritative values and never serialized.

Input is finite-clamped to `[0,1]`; nonfinite becomes zero. Equal and reversed endpoints are valid.

For `reciprocal_temperature`, row lowering computes bounded `x0=1023*q(T0)`, `x1=1023*q(T1)`, `dx=x1-x0`; per sample uses `x=fma(u,dx,x0)`. For `linear_kelvin`, per sample computes `T=lerp(T0,T1,u)` then `x=1023*q(T)`. Sampling clamps x, guards x=1023, otherwise floors x and manually interpolates adjacent internal-linear-RGB entries.

The generated initializer is the single byte authority. `blackbody_palette_lut.h` owns an `inline constexpr` host table and, under CUDA compilation, a TU-local `static __device__ __constant__` table from the same initializer. No runtime upload, external device linkage, relocatable device code, or duplicate handwritten table is allowed.

## State, Capture, And Cache Authority

`state.json` serializes only palette id, endpoints, mapping, blend weight, and blend mode for each Palette row. Old states omit the new keys and retain existing defaults. `fractal-state.json`, graph receipts, and runtime reports expose the same authoritative values; derived LUT coordinates may be reported only when labelled derived.

A fixed stale-cache sequence evaluates one signal at `(T0,T1,mode)`, changes only T0, changes only T1, then changes only mode. Every result must equal a freshly lowered row and the uncached reference. Load/replay uses non-default `T0=2400`, `T1=18000`, `linear_kelvin`; defaults-only replay does not qualify.
